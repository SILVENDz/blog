# Sil's Website
## Description:
This is a personal website designed for showcasing my hobbies, interests, and communication between other's who share similar interests. It includes various features, such as a guestbook and comment sections, in order for others to share their own thoughts and likes!This is my own corner of the internet for self expression and to bring back that retro feeling of exploring self-made websites! I made this to expand my knowledge on coding with HTML/CSS, getting used to software like VScode, and to create something that is uniquely mine

## Features:
* Pages dedicated to topics of interest within certain internet niches
* Navigation bar that allow's website visitors to switch between different pages
* A "more" page that includes links to more of my content, including an Itch.io page
* Comment section widget for interactivity


## How it Works:
* Used HTML for website layout. Used header, nav, paragraph, article, and image tags in order to add more content to each of the pages.
* Used CSS to make the HTML structure visually appealing. Examples include marquees for scrolling text, background images for each page, color pallets, interactive buttons, and pixel typography
